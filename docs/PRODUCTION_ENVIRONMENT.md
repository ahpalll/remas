# PRODUCTION ENVIRONMENT ARCHITECTURE

## 1. Multi-Tier Environment Strategy

REMAS Educational Center SaaS defines three strictly separated environments:

| Environment | Purpose | Infrastructure Scope | Data Isolation |
| :--- | :--- | :--- | :--- |
| **Development (`DEV`)** | Local dev, emulator testing, active feature coding | Firebase Emulators (Auth, Firestore, Functions), Local Worker Mock | Isolated local state |
| **Staging (`STAGING`)** | Pre-production testing, UAT, integration verification | Dedicated Staging Firebase Project, Staging Worker, Staging R2 | Synthetic test data |
| **Production (`PRODUCTION`)** | Real operational tenant data, parent/student access | High-availability Cloud Firebase, Worker Edge, R2 Storage | Strict tenant boundary |

## 2. Infrastructure Component Matrix

### 2.1 Firebase Ecosystem
- **Firebase Project ID**: Controlled via `FIREBASE_PROJECT_ID` (`remas-dev`, `remas-staging`, `remas-prod`).
- **Firestore Database**: Multi-tenant database per environment with rules enforcing tenant & role isolation.
- **Authentication**: Email/Password + Custom Claims (`institutionId`, `role`, `tenantId`).
- **Cloud Functions / Trusted Backend**: Server-side APIs handling privileged operations.

### 2.2 Cloudflare Edge Ecosystem
- **Cloudflare Worker**: Edge validation layer for secure media delivery.
- **Cloudflare R2 Bucket**: Private object storage (`R2_BUCKET_NAME`). Public direct access disabled.
- **Signed URLs**: Temporary read access generated by Edge Worker or Backend. Maximum TTL 3600 seconds.

### 2.3 FCM (Firebase Cloud Messaging)
- Server-side payload dispatch for System and Academic notifications.
- Client token registration per device with auto-cleanup for invalid tokens.

### 2.4 Application Delivery
- **Admin Web Portal**: React application built for specific environment API endpoints.
- **Parent Web Portal**: React application for parent dashboard.
- **Student Mobile App**: Flutter app built with target environment configuration flags (`--dart-define`).
- **Parent Mobile App**: Flutter app built with target environment configuration flags (`--dart-define`).

## 3. Environment Variables Matrix (Placeholders Only)

| Variable Name | Required In | Description |
| :--- | :--- | :--- |
| `NODE_ENV` | All | `development`, `staging`, or `production` |
| `FIREBASE_PROJECT_ID` | All | Target Firebase Project identifier |
| `FIREBASE_CLIENT_EMAIL` | Backend | Service Account Email (Production / Staging) |
| `FIREBASE_PRIVATE_KEY` | Backend | Service Account Private Key (Production / Staging) |
| `CLOUDFLARE_ACCOUNT_ID` | Backend / Edge | Cloudflare Account ID |
| `CLOUDFLARE_API_TOKEN` | Edge Deploy | API Token for Worker Deployment |
| `R2_BUCKET_NAME` | Backend / Edge | R2 Media Bucket Identifier |
| `R2_ACCESS_KEY_ID` | Backend | R2 Access Key ID |
| `R2_SECRET_ACCESS_KEY` | Backend | R2 Secret Access Key |
| `JWT_ISSUER` | Backend / Edge | Token Issuer Identifier |
| `JWT_AUDIENCE` | Backend / Edge | Token Audience Identifier |
| `FCM_SERVER_KEY` | Backend | FCM Messaging Service Credentials |

> **SECURITY NOTE**: All production secrets MUST be stored in encrypted secret managers (e.g. GitHub Secrets, Cloudflare Secrets, Google Cloud Secret Manager). NEVER commit secrets to source code.
